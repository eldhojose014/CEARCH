CE ARCH BUILDERS - WEBSITE
==========================
index.html   the whole website (one page)
favicon.svg  browser tab icon
logo-mark.svg  logo mark (gold line house)

PUT IT ONLINE (free, about 5 minutes)
1. Netlify Drop: go to app.netlify.com/drop and drag this whole folder onto the page.
   You get a live address like something.netlify.app at once.
2. Or Cloudflare Pages / GitHub Pages: upload the folder and publish.

USE YOUR OWN DOMAIN (example: cearchbuilders.in)
1. Buy the domain from GoDaddy, Namecheap, BigRock or similar.
2. In Netlify (or Cloudflare Pages) open Domain settings, add your domain,
   and copy the DNS records they show into your domain provider.
3. HTTPS is added automatically.

EDITING
Open index.html in any text editor. Phone, email and text are plain words in the file.

ADDING PROJECTS (no coding)
1. Open add-project.html (on the live site: yoursite.netlify.app/add-project.html).
2. Fill in the project, add photos, press "Add this project". Repeat for more projects.
   There you can also remove a project or mark an ongoing one as completed.
3. Press "Download update file". Unzip it into this website folder (choose Replace).
4. Upload the website folder to Netlify again. Done.
Photos are shrunk automatically. The gallery shows 9 projects at a time with a
"Show more" button, so the site stays fast with hundreds of projects.
Keep add-project.html private: nobody can change your site with it, but there is no reason to share the address.

OTHER EDITABLE PARTS (index.html)
REVIEWS: client reviews. Leave empty to hide the section.
FAQ answers: search for id="faq".

MORE OPTIONS (index.html, same place as PROJECTS)
AREAS         towns you serve, shown as tags.
CREDENTIALS   licences and registrations. Add real ones only.
SOCIAL        Instagram, Facebook, Google reviews links for the footer.
Each section appears only when it has entries.
